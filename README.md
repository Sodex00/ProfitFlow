## О проекте

ProfitFlow — клиентское React-приложение для самостоятельного учёта криптовалютных операций. Оно объединяет спотовый портфель, симулятор фьючерсов, живой свечной график, журналы сделок и аналитику результатов.

Приложение не требует регистрации. Профиль, настройки и сделки хранятся локально в браузере пользователя.

## Спотовая торговля

- Правильный сценарий работы: **покупка → хранение → продажа**.
- Покупка указывается суммой в выбранной валюте, а количество монет рассчитывается автоматически.
- Поддерживаются `USD`, `RUB` и `EUR`; курсы конвертации обновляются через валютный API.
- Цена покупки и продажи может быть введена вручную.
- Если поле цены оставить пустым, используется актуальная рыночная цена на момент подтверждения.
- Ручной ввод не перезаписывается при обновлении рынка.
- Take Profit и Stop Loss задаются в процентах от цены покупки.
- Активные покупки можно редактировать или продать по ручной/рыночной цене.
- Сделка раскрывается и показывает ожидаемую прибыль, риск, Risk/Reward и ориентировочную вероятность достижения цели.
- История покупок и продаж сохраняется в отдельном спотовом журнале.

## Фьючерсы

- Отдельная страница для Long и Short позиций.
- Выбор маржи и кредитного плеча от `1×` до `50×`.
- Автоматический расчёт размера позиции, комиссии и ориентировочной цены ликвидации.
- Фьючерсные позиции сохраняются в собственном журнале.
- Модуль работает как локальный симулятор риска и не отправляет реальные ордера на биржу.

## Рынок и графики

- Реальные котировки Binance через WebSocket.
- Автоматическое переподключение при потере соединения.
- Настоящие Kline-свечи Binance вместо сгенерированной трендовой линии.
- Интервалы `1m`, `5m`, `15m`, `1h`, `4h` и `1d` загружают отдельные серии свечей.
- Текущая свеча обновляется в реальном времени.
- Обратный отсчёт до закрытия свечи для выбранного интервала.
- Горизонтальные отметки открытых входов с идентификатором сделки.

## Аналитика

- Общий P&L, торговый объём, винрейт и открытые позиции.
- Доходы и расходы за день, неделю, месяц и год.
- Количество прибыльных и убыточных сделок.
- Распределение портфеля по активам.
- Автоматический расчёт результата в деньгах и процентах.

## Профиль и настройки

- Имя и email локального профиля.
- Основная валюта: `USD`, `RUB` или `EUR`.
- Настраиваемый риск на сделку.
- Параметры подтверждения удаления и рыночных уведомлений.
- Настройки сохраняются между сессиями браузера.

## Интерфейс

- Тёмная адаптивная панель для компьютеров, планшетов и телефонов.
- WebGL-анимация запуска на Three.js / React Three Fiber.
- Отдельные страницы спота, фьючерсов, аналитики и настроек.
- Увеличенная типографика, интерактивные карточки и состояния подключения рынка.

## Быстрый запуск

Требуется Node.js 22 или новее.

```bash
git clone https://github.com/Sodex00/ProfitFlow.git
cd ProfitFlow
npm install
npm run dev
```

После запуска Vite покажет локальный адрес приложения в терминале.

## Хранение и приватность

Все пользовательские сделки и настройки хранятся в `localStorage` текущего браузера. ProfitFlow не передаёт журнал на собственный сервер и не имеет доступа к биржевому аккаунту пользователя.

Очистка данных сайта в браузере удалит локальный журнал. Для важных записей рекомендуется хранить отдельную резервную копию.

## Источники данных

- Binance REST API — исторические свечи и резервное получение цены.
- Binance WebSocket — поток текущей цены и обновление открытой свечи.
- Exchange Rate API — конвертация USD, RUB и EUR.

При недоступности внешнего API интерфейс сохраняет последнюю доступную или резервную цену.
